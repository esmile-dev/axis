## Project Overview

This project is a productivity tool for managing the software development lifecycle - from idea capture to implementation. The `前提idea.md` describes the core philosophy and requirements.

## Development Philosophy (from PRD)

The methodology follows four phases:
1. **诊断期 (Diagnosis)**: Collect requirements from real pain points
2. **收敛期 (Convergence)**: Define bounded contexts using DDD
3. **设计期 (Design)**: Use Jobs-To-Be-Done framework - format: `当 [特定场景] 时，我想要 [采取的具体行动]，以便于 [获得什么预期效果]`
4. **破冰期 (Ice-breaking)**: Vibe coding

## Core Pain Points to Address

- Time fragmentation - capturing ideas quickly before losing inspiration
- Need a "space to nurture requirements" (kanban-style pipeline)
- Pipeline: idea → PRD → implement → verify → CI/CD
- Knowledge base for tech/tool learning
- Inbox for RSS, bot-collected info, and task results
